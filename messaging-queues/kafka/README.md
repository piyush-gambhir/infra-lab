# Kafka

This directory is intended for running Apache Kafka using Docker Compose.

## Usage

1. Ensure a `docker-compose.yaml` file is present in this directory.
2. Run the following command in this directory:

```powershell
# Start Kafka
docker compose -f docker-compose.yaml up -d
```

## Configuration

-   Customize the `docker-compose.yaml` file as needed for your environment.
