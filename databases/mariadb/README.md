# MariaDB

This directory is intended for running MariaDB using Docker Compose.

## Usage

1. Ensure a `docker-compose.yml` file is present in this directory.
2. Run the following command in this directory:

```powershell
# Start MariaDB
docker compose up -d
```

## Configuration

-   Customize the `docker-compose.yml` file as needed for your environment.
