# Grafana & Prometheus

This directory is intended for running Grafana and Prometheus using Docker Compose.

## Usage

1. Copy or create a `docker-compose.yml` file in this directory.
2. Run the following command in this directory:

```powershell
# Start Grafana and Prometheus
docker compose up -d
```

## Configuration

-   Customize the `docker-compose.yml` file as needed for your environment.
